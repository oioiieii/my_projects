# my_projects
Мои работы и пет-проекты, разработанные в процессе обучения в вузе (от простых лаб до курсовых пректов)

PortModel - первое знакомство с ООП на примере модели работы порта (взаимодействие объектов корабль, порт и т.д.)
Кратко: горжусь получившимся визуалом и идеей с ее реализацией, с точки зрения кода отсутствие построенной архитектуры + местами запутанный код  

CoffeMachine - второе знакомство с ООП на примере работы кофемашины (взаимодействие объектов человека и кофемашины)
Кратко: визуал не плох, более структурированный код (не знал как минимум про SOLID, от того нарушен принцип D)

Алгоритмы на C++
1- вспомнил ООП
2- знакомство с интерфейсами
3- работа с графом, поиск кратчайшего маршрута
4- задача о максимальном потоке и назначенияз
5- различная рбота с деревьями (построение, обходы, удаление и т.д.)
6- работа с файлами (запись/чтение из XML файла)
7- работа с БД (MySQL)
8- паралельное вычисление (OpenMP)
